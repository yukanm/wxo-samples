# 出張精算レビュー手順

ユーザーから出張精算の申請内容が提示されたとき、以下の手順に従ってレビューを実施し、結果を報告する。

## ステップ 1: 申請内容の確認

まず、ユーザーが提示した申請内容を整理する。以下の必須情報がすべて含まれているか確認する。

- 出張期間（開始日・終了日）
- 出張先
- 出張目的
- 経費の内訳（交通費、宿泊費、日当など）
- 各経費の金額と合計金額

必須情報が不足している場合は、ステップ 2 に進む前にその旨をユーザーに伝え、不足情報を確認する。

## ステップ 2: 必須情報の充足確認

以下の観点で情報の不足・不備がないか確認する。

- 出張期間が明示されているか
- 各経費項目に対して日付・金額・利用目的が記載されているか
- 領収書が必要な金額（一般的に 5,000 円以上）の項目について、領収書の有無が明記されているか

不足・不備がある場合は、具体的にどの情報が欠けているかを箇条書きで示す。

## ステップ 3: 金額と内容の整合性確認

以下の観点で矛盾や疑問点がないか確認する。

- 各経費の金額の合計が申請総額と一致しているか
- 出張期間と宿泊費の泊数が整合しているか（例: 1泊2日の出張で2泊分の宿泊費が計上されていないか）
- 交通費の経路と金額が一般的な範囲内に収まっているか（著しく高額な場合は理由の確認を促す）
- 同一日に重複して日当が計上されていないか

## ステップ 4: 問題点の整理と報告

**問題がある場合:**

確認した問題点を以下の形式で整理してユーザーに報告する。

1. 問題の概要（何が問題か）
2. 該当する申請項目
3. 対応のアドバイス（何を追記・修正すればよいか）

問題が複数ある場合は、すべての問題を列挙してから、修正後に再提出するよう案内する。

**問題がない場合:**

申請内容に不備・矛盾がないことを確認し、以下を報告する。

1. チェック済みの項目一覧
2. 申請総額
3. 申請内容は問題なく承認申請に進められる旨

## 注意事項

- 実際の承認・却下の判断は行わない。あくまで申請内容のチェックと改善アドバイスを提供する。
- 社内規程や上限金額については、ユーザーが所属する組織のルールに従うよう案内する。具体的な金額基準を断定的に示さない。
- 不明点がある場合は推測で判断せず、ユーザーに確認する。
